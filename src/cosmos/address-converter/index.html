🔄 Address Converter

Convert an address between chain prefixes, and between account, validator operator and consensus forms.

How it works

A Cosmos address is just bytes (usually 20, the hash of a public key) encoded with bech32 and a human-readable prefix. Changing the prefix keeps the same bytes, so the same key controls the address on every chain that derives keys the same way (coin type 118). Chains with a different coin type (Terra 330, Kava 459, Secret 529, Cronos 394) or Ethereum-style keys (Injective, Evmos) derive a different address from the same mnemonic, so a converted address there is only useful if you know the bytes are right for that chain.

Validator operator addresses (…valoper) are the operator's account bytes under a different prefix; consensus addresses (…valcons) come from the node's consensus key instead, so converting an account to valcons gives the right format but not the validator's actual consensus address.

32-byte addresses belong to modules, interchain accounts or smart contracts rather than to a single key.
