🎭 Pure Proxy

Derive the address of a pure proxy (formerly "anonymous proxy") from the transaction that created it.

Proxy type indexes are defined by each runtime and have changed over time (for example when IdentityJudgement was removed). The list above is for the Polkadot and Kusama relay chains; Asset Hub and other parachains have their own ProxyType enum — pick “Other index…” and check your chain's metadata if the address doesn't match.

Account id = Blake2b-256("modlpy/proxy____" ‖ spawner ‖ block number as u32 ‖ extrinsic index as u32 ‖ proxy type as u8 ‖ index as u16), as in pallet_proxy::pure_account.
