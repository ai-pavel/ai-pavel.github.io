🗝️ Address from Key

Derive a Sui address from an Ed25519, Secp256k1 or Secp256r1 public key.

How it works

Address = BLAKE2b-256(flag ‖ public key), where the flag is one byte for the signature scheme: 0x00 Ed25519 (32-byte key), 0x01 Secp256k1 and 0x02 Secp256r1 (33-byte compressed keys). The “Sui public key” format used by wallets and the CLI is base64 of flag ‖ public key, so it already says which scheme it is.

A bare 33-byte compressed key could be either Secp256k1 or Secp256r1, so Auto-detect shows both addresses; pick the scheme to see one.
