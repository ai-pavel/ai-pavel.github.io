🌱 Mnemonic Accounts

Derive Sui accounts from a BIP-39 mnemonic, the way Sui wallets and the CLI do.

How it works

The mnemonic becomes a 64-byte seed with BIP-39 (no passphrase, as in Sui wallets). Ed25519 keys use SLIP-0010, where every path index is hardened. Secp256k1 and Secp256r1 keys use BIP-32 derivation; Sui uses the same BIP-32 tree for both and treats the resulting 32 bytes as a Secp256r1 key for the r1 scheme. The address is BLAKE2b-256(flag ‖ public key).
