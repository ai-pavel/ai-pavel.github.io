✔️ Verify Message

Verify a message signed with a Cardano wallet (CIP-8 / CIP-30 signData), for example a "sign in with Cardano" request.

What gets checked

The wallet signs a COSE structure: ["Signature1", protected headers, external_aad, payload]. The protected headers name the algorithm (EdDSA) and the signing address. This tool rebuilds that structure, checks the Ed25519 signature with the public key, and checks that the key's hash matches the address's payment (or stake) credential, so the signature really comes from that address.
