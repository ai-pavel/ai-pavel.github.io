👥 Multisig Address

Derive a multisig address from public keys, weights and a threshold.

Use Sui public keys (base64 of flag ‖ key, as shown by wallets and sui keytool). For a raw key, prefix the scheme: ed25519:, secp256k1: or secp256r1:. Weight defaults to 1.

How it works

Address = BLAKE2b-256(0x03 ‖ threshold as u16 little-endian ‖ for each signer: flag ‖ public key ‖ weight as u8), with signers in the order you list them. Changing the order, a weight or the threshold gives a different address. A multisig has 1–10 signers, weights 1–255, and a threshold from 1 to the total weight.
